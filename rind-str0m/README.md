<h1 align="center">rind-str0m</h1>
<img width="40%" align="right" src="https://raw.githubusercontent.com/kixel-ai/rind/main/admin/logo.png">

[![Latest release](https://img.shields.io/crates/v/rind-str0m)](https://crates.io/crates/rind-str0m)
[![Documentation](https://img.shields.io/docsrs/rind-str0m)](https://docs.rs/rind-str0m/)

This crate provides a `CryptoProvider` for [str0m](https://github.com/algesten/str0m), backed by [rind](https://github.com/kixel-ai/rind/), a fork of [Graviola](https://github.com/ctz/graviola/).

Build str0m with `default-features = false`, since its default features compile aws-lc-rs.
Then hand the provider to each connection:

```rust
use std::sync::Arc;
use std::time::Instant;

let provider = rind_str0m::default_provider();
let rtc = str0m::Rtc::builder()
    .set_crypto_provider(Arc::new(provider))
    .build(Instant::now());
```

Or install it for the process with `str0m::crypto::CryptoProvider::install_process_default`.

It protects SRTP with AES-128-CM-HMAC-SHA1-80, AEAD-AES-128-GCM, and AEAD-AES-256-GCM, signs STUN with HMAC-SHA1, and hashes certificate fingerprints with SHA-1 and SHA-256.
DTLS 1.2 and 1.3 run through dimpl on [rind-dimpl](https://github.com/kixel-ai/rind/tree/main/rind-dimpl), with a self-signed ECDSA P-256 certificate generated by [rind-rcgen](https://github.com/kixel-ai/rind/tree/main/rind-rcgen).
`dimpl_crypto_provider()` returns that dimpl provider, for building your own `dimpl::Config`.

Where str0m-aws-lc-rs lets dimpl panic on an empty DTLS certificate or a private key it cannot load, this returns an error.

A generated certificate's private key is returned in dimpl's `DtlsCertificate`, whose plain `Vec<u8>` str0m owns and nothing wipes when it is dropped.

It builds for `wasm32-wasip2` and `wasm32-unknown-unknown`, the browser, where
rind needs its JavaScript random source, `getrandom = { version = "0.4",
features = ["wasm_js"] }`. [PLATFORMS.md](https://github.com/kixel-ai/rind/blob/main/PLATFORMS.md) lists what each adapter's
upstream needs there too, and why rind's constant-time checks do not cover wasm.
