# [M] rind on 32-bit x86

## Goal

rind and rind-rustls build for i686-unknown-linux-gnu, i686-pc-windows-msvc, and i686-linux-android on the [portable backend](/ARCHITECTURE.md), and CI runs the test suite (Wycheproof, differential, rind-rustls handshakes) under qemu on each.

## Plan

Android x86 and 32-bit Windows are the likeliest consumers. libcrux-platform 0.0.4, which libcrux-aes pulls in, calls `__cpuid` outside `unsafe`, which compiles only on Rust newer than rind's 1.90 MSRV on x86: raise the MSRV, or get libcrux to fix it, before i686 can claim it. i586 is out: ring refuses it for lacking SSE2, and aws-lc-rs doesn't test it. aws-lc has x86 assembly, but it's out of scope until a consumer measures a need. A missing CPU feature still fails with an error naming it; the portable backend needs none. Add the targets to [PLATFORMS.md](/PLATFORMS.md) and the release checks in the same PR.
